## Задание 2. Создание и запуск первой PHP-программы

В рабочей директории был создан файл:

```text
index.php
```

В него был записан PHP-код:

```php
<?php

echo "Привет, мир!<br />";

echo "Hello, World with echo!<br />";
print "Hello, World with print!<br />";

$days = 288;
$message = "Все возвращаются на работу!";

echo "<br />";

echo "Вывод с использованием конкатенации:<br />";
echo "Количество дней: " . $days . "<br />";
echo "Сообщение: " . $message . "<br />";

echo "<br />";

echo "Вывод с использованием двойных кавычек:<br />";
echo "Количество дней: $days<br />";
echo "Сообщение: $message<br />";
```

Тег `<?php` обозначает начало PHP-кода.

Конструкция `echo` используется для вывода данных. `print` также выводит данные, но имеет некоторые отличия от `echo`, которые рассмотрены ниже.

Закрывающий тег `?>` в конце файла не используется, поскольку файл состоит только из PHP-кода.

## Задание 4. Вывод данных с помощью `echo` и `print`

В программе использованы оба способа вывода:

```php
echo "Hello, World with echo!<br />";
print "Hello, World with print!<br />";
```

В данном примере визуальный результат почти одинаковый.

Для переноса строки используется HTML-тег:

```html
<br />
```

Это связано с тем, что браузер отображает полученный результат как HTML.

## Задание 5. Работа с переменными

По условию были созданы две переменные:

```php
$days = 288;
$message = "Все возвращаются на работу!";
```

Переменная `$days` содержит целое число, а `$message` содержит строку.

### Вывод с использованием конкатенации

В PHP для объединения строк используется оператор `.`:

```php
echo "Количество дней: " . $days . "<br />";
echo "Сообщение: " . $message . "<br />";
```

Здесь строка и значение переменной объединяются перед выводом.

### Вывод с использованием двойных кавычек

Те же значения были выведены с помощью двойных кавычек:

```php
echo "Количество дней: $days<br />";
echo "Сообщение: $message<br />";
```

В двойных кавычках PHP распознаёт переменные внутри строки и подставляет их значения.

Оба варианта дают одинаковый результат, но используют разные способы формирования строки.

## Контрольные вопросы

### 1. Какие способы установки PHP существуют?

PHP можно установить отдельно, скачав архив с официального сайта, распаковав его и добавив путь к PHP в системную переменную `Path`.

Другой вариант заключается в использовании готовой сборки, например XAMPP. В этом случае PHP устанавливается вместе с Apache и другими инструментами.

В данной работе использовалась отдельная установка PHP.

### 2. Как проверить, что PHP установлен и работает?

Для проверки установки можно использовать команду:

```bash
php -v
```

Если PHP установлен правильно и доступен через `Path`, команда выводит его версию.

Дополнительно работу PHP можно проверить запуском встроенного веб-сервера:

```bash
php -S localhost:8000
```

После этого при открытии `http://localhost:8000` браузер получает результат выполнения файла `index.php`.

### 3. Чем отличается `echo` от `print`?

`echo` и `print` используются для вывода данных.

`echo` может принимать несколько значений и ничего не возвращает.

`print` принимает одно значение и возвращает `1`, поэтому его можно использовать внутри выражений.

Для обычного вывода текста чаще используется `echo`.
